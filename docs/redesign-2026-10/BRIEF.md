# 프라임에셋.com 개편 — 시안 제작 지침서 (2026-10-07)

시안 A(Claude)와 시안 B(Codex)가 **같은 내용**을 **서로 다른 디자인·모션**으로 만든다. 사장님이 둘을 보고 방향을 고른다.

## 1. 누구에게, 무엇을
- **보는 사람**: 보험설계사(신입·경력)와 본부장 후보. 처음 이 사이트에 들어온 사람.
- **한 줄 메시지**: 「프라임에셋 어메이징사업부에 오면 **보메이트**를 쓰면서 일한다 — 상담 준비가 달라진다 — 그래서 우리에게 오면 좋다.」
- **보메이트** = 어메이징사업부가 **직접 개발·운영하는** 보험설계사 상담 준비 프로그램. 이 사이트에서 가장 크게 보여야 할 주인공이다.
- 지금 사이트(참고: `_시안_확인용/0_지금_홈페이지_진단.html`, 문구 `_시안_확인용/0_지금_문구.txt`)는
  보메이트가 0회, 「AI」 30곳, 01·02·03 번호 카드 격자 반복, 남색·보라 그라데이션, 영어 구호, 휴대폰 31,000px 길이다. 전부 고친다.

## 2. 이번 시안 범위 (빨리 비교하려고 두 구역만)
1. **첫 화면** — 한 문장 + 보메이트가 실제로 움직이는 모션(정지 이미지 금지)
2. **보메이트 시연 구역** — 스크롤하면 상담 준비 흐름이 단계별로 펼쳐진다
   - 설계사가 고객에게 **카카오톡 링크**를 보낸다
   - 고객이 휴대폰에서 **간편인증**한다 (★「한 번 인증」 금지: 지금은 기관 3곳을 각각 승인한다, 2026-10-07 확인)
   - **진료내역 · 건강검진 · 실손 미청구 확인 자료**가 모인다
   - **분석**: 고지 분석(고지할 진료) · 실손 미청구 찾기 · 보장 비교
   - **상담 리포트**가 한 화면에 완성된다 → 설계사는 고객 앞에서 이야기만 하면 된다
3. 그 아래에 **「우리에게 오면」 구역의 짧은 맛보기** 1개(입사 첫날 보메이트 전체 사용 · 10일 교육 · 32개 제휴사) + 지원하기 버튼.
   완성본에서 늘린다.

## 3. 쓸 수 있는 사실 (이것 밖의 숫자·주장은 만들지 마라)
- 보메이트 공식 소개: 「보험설계사의 상담 준비를 돕는 프로그램. 고객이 카카오톡 링크로 한 번 인증하면 진료내역·건강검진·실손 미청구 확인 자료와 상담 리포트가 한 화면에 정리된다.」
- 보메이트 도구 이름(실제 존재): 통합조회 · 진료내역 조회(고지 분석) · 의료비·실손 미청구 · 정밀 미청구 · 청구 누락 체크 · 보장 비교(전후 비교·상담 멘트) · 건강검진 리포트 · 통합 리포트 · 세일즈 코칭 · 청구 사례집 · 약관실 · 질문방
- 조직 사실(이미 공개됨): 프라임에셋 소속 어메이징사업부 · 생보 19 + 손보 13 = **32개 제휴사** · 신입 **10일** 교육(매월 1일/15일 개강) · 교육 교재 **74쪽** · **2개 본부(067·290, 2026-10-07 확인 — 292 없음)**
- 예시 화면의 고객·숫자는 전부 가짜로: 「김○○ 고객 · 50대」, 금액은 예시임이 드러나게. **실명·실제 생년월일·실제 병원명 금지.**

## 4. 금지
- 「AI」「인공지능」「GPT」「자동 생성」 같은 단어. 기능은 **보메이트 기능 이름**으로 말한다.
- 보라·파랑 네온 그라데이션 / 01·02·03 번호 카드 격자 / 카드 안의 카드 / 영어 구호
- 출처 없는 비율·성약률·소득 금액·「최고」「역대급」「무조건」「지금 바로」 같은 과장·절판 표현
- 보험회사명·상품명, ₩·동전·지폐·저금통 그림(보험 광고 규칙)
- 이모지를 아이콘 대신 쓰기

## 5. 디자인 기준 (사내 `UI_DESIGN_PRINCIPLES` — 공개 페이지 C 분류)
- 글꼴: 이미 로드된 `var(--font-sans-kr)`(Noto Sans KR → Pretendard), 제목 강조에 `var(--font-serif-display)`(Noto Serif KR) 사용 가능
- 크기 단계는 1.333배 모듈러 스케일 + `clamp()`, 제목 줄높이 1.15~1.25 · 본문 1.5~1.65, 숫자는 `tabular-nums`
- 색: 틴티드 뉴트럴(순수 #000·#fff·#888 금지), 대비 4.5:1 이상. 의미색 — 받을 돈=앰버, 위험=레드, 확인 필요=바이올렛, 완료=브랜드 teal
- 여백은 4의 배수, 정보는 카드를 늘리지 말고 여백·구분선·타이포 위계로
- 모션: `transform`·`opacity` 만, 나타날 땐 ease-out, `prefers-reduced-motion` 이면 모션 끄고 최종 상태를 보여 준다
- 휴대폰 먼저(기준 폭 360px), 터치 44px 이상, **가로 스크롤 금지**, 1440px PC 에서도 완성도

## 6. 기술
- Next.js 14 app router · Tailwind · `framer-motion` · `gsap`(ScrollTrigger 포함, 무료) · `lenis` 설치돼 있음. **다른 패키지 추가 금지.**
- 시안 A: `app/sian-a/page.tsx` + `components/sian-a/**` / 시안 B: `app/sian-b/page.tsx` + `components/sian-b/**`
  **자기 폴더 밖의 파일은 수정·삭제 금지**(기존 홈페이지·설정·package.json 포함).
- 클라이언트 모션은 `'use client'` 컴포넌트로. 이미지는 코드로 그린 화면(SVG·div)을 우선 — 외부 이미지 링크 금지.
- `npx tsc --noEmit` 통과.
