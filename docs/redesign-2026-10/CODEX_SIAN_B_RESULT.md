# 시안 B 결과 보고

## 고른 디자인 방향과 이유

시안 B는 **어두운 제품 무대형**으로 만들었다. 종이·기사 느낌의 시안 A와 달리, 짙은 틴티드 뉴트럴 배경 위에서 보메이트 화면이 조명을 받은 실제 제품처럼 크게 등장한다. 청록은 완료와 제품 브랜드, 앰버는 확인할 자료, 레드는 고지 확인에만 제한해 기능의 의미가 색으로 읽히게 했다.

첫 화면의 중심은 조직 소개가 아니라 움직이는 보메이트다. 「상담 준비가 달라지면, 고객과의 대화가 달라집니다」라는 한 문장 옆에서 링크 전송부터 상담 리포트까지 제품 화면이 순환한다. 시연 구역도 번호 카드를 늘어놓지 않고, 하나의 큰 화면이 스크롤에 맞춰 계속 재구성되도록 했다. 보험설계사가 실제로 겪는 준비 순서를 한 제품 안에서 따라가게 하기 위한 선택이다.

모바일에서는 제목과 제품을 위아래로 배치하고, 390px 안에서 제품 화면 전체가 잘리지 않도록 크기와 내부 정보 밀도를 조정했다. PC에서는 큰 타이포그래피와 제품 화면을 좌우로 맞세워 무대처럼 보이게 했다.

## 모션 설계

- 첫 화면 진입 시 문장과 제품 화면이 아래에서 짧게 올라오며 나타난다.
- 첫 화면의 보메이트는 `링크 전송 → 한 번 인증 → 자료 확인 → 분석 → 상담 리포트` 순서로 약 2.2초마다 화면 내용이 바뀐다. 현재 흐름은 제품 위의 짧은 상태명과 진행선으로 함께 표시한다.
- 보메이트 시연 구역은 화면을 고정한 채 스크롤 진행도에 따라 같은 다섯 상태가 바뀐다. 왼쪽 설명과 아이콘은 위아래로 교체되고, 오른쪽 제품 화면은 내용만 전환돼 하나의 프로그램을 계속 쓰는 느낌을 유지한다.
- 인증 화면의 전송 점, 자료 확인 진행선, 첫 화면의 아래 안내 화살표에는 작은 반복 움직임만 사용했다.
- 모든 전환은 `opacity`와 `transform` 중심이다.
- `prefers-reduced-motion: reduce`에서는 반복·진입 모션과 긴 고정 스크롤을 끄고, 첫 화면과 시연 화면 모두 최종 상담 리포트 상태를 바로 보여 준다.
