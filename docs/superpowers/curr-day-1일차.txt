보류 비용 구조 DB 1건당 — 상품군·품질에 따라 차이. 성약률로 ROI 계산 필수 ▶ 2. 온라인 영업 — 블로그 & 카페 운영 온라인 영업은 설계사 자신이 인터넷 공간에 전문적인 콘텐츠를 쌓아 고객이 스스로 찾아오도록 만드는 방식입니다. 초기 투자 시간이 많지만 장기적으로 가장 강력한 채널입니다. ◆ 블로그 운영 전략 (네이버 블로그 기준) 📝 블로그 콘텐츠 3가지 유형 ① 정보성 글: "40대 실손보험 꼭 알아야 할 5가지" → 검색 유입 → 신뢰 형성 ② 비교분석 글: "A보험 vs B보험 실제 비교" → 구체적 니즈 고객 유입 ③ 경험담/후기 글: "제가 직접 암 보험금을 청구해봤습니다" → 공감 → 문의 [ 글 구성 공식 ] 제목(검색키워드) → 도입부(공감) → 본문(정보) → 결론(CTA: "무료상담 신청") [ 업로드 주기 ] 주 2~3회 정기 업로드. 꾸준함이 검색 노출의 핵심 [ 핵심 키워드 ] "실손보험 추천", "암보험 비교", "운전자보험 필요한가" 등 검색량 높은 키워드 먼저 ◆ 카페 운영 전략 (네이버 카페 기준) 카페는 블로그보다 커뮤니티 성격이 강합니다. 고객들이 서로 정보를 교환하는 공간으로 설계사는 "전문가 도우미" 포지션을 잡아야 합니다. 단계 행동 원칙 진입 단계 카페 가입 후 2주간 판매 멘트 없이 정보만 제공 → 신뢰 먼저 쌓기 댓글 단계 보험 관련 질문 글에 성실하고 구체적인 답변 달기 → 전문가 인식 구축 연결 단계 "더 자세한 내용은 쪽지 주세요" → 1:1 상담으로 자연스럽게 전환 전환 단계 쪽지 상담 → 전화 상담 → 대면 미팅 순으로 단계적 신뢰 쌓기 ⚠️ 주의: 카페에서 처음부터 "가입 문의 주세요"라고 하면 스팸 취급을 받아 오히려 신뢰를 잃습니다. ▶ 3. 개척 영업 — 직접 고객을 찾아가는 방식 개척 영업은 아직 나를 모르는 사람에게 먼저 다가가는 방식입니다. 체력과 멘탈이 요구되지만, 가장 직접적인 고객 발굴 방법입니다. 개척 유형 주요 방법 핵심 포인트 지역 개척 아파트 단지, 상가 방문 반복 방문으로 얼굴 익히기 → 관계 → 계약 인맥 개척 지인, 동창, 직장동료 "나 보험 시작했어" 알리기 → 소개 요청 소개 개척 기존 고객에게 소개 부탁 "좋은 분 소개해주시면 제가 더 열심히" → 서비스 이벤트 개척 지역 행사, 마켓 참가 무료 보험 점검 서비스로 접근 온·오프 연계 블로그 독자를 오프라인으로 온라인 신뢰 → 오프라인 미팅 전환 성약률 높음 ▶ 4. 보험영업 전체 프로세스 흐름도 🔄 영업 사이클 8단계 ① 고객 발굴 (DB / 블로그 / 개척 / 소개) → 연락처 확보 ② TA(Telephone Approach) → 전화 첫 접촉, 미팅 약속 잡기 ③ 1차 미팅 (FA 면담) → 니즈 파악, 신뢰 구축, 건강고지 사전 확인 ④ 설계 작성 → 고객 맞춤 상품 설계, 비교 자료 준비 ⑤ 2차 미팅 (설계 제안) → 설계서 설명, 가격 제시, 클로징 ⑥ 청약서 작성 → 모바일 or 종이 청약, 고지의무 확인, 서명 ⑦ 증권 전달 → 계약 확인, 감사 인사, 관계 유지 ⑧ 유지 관리 → 갱신 안내, 추가 니즈 파악, 소개 요청 💡 TIP: 계약이 끝난 고객이 가장 좋은 소개 채널입니다. 증권 전달 시 "좋은 분 한 분만 소개해주세요"라고 자연스럽게 요청하세요. 1일차 2부 (1시간) — 보험 필수 용어 완전 정복 보험 용어를 정확히 알아야 고객과 대화할 때 자신감이 생기고, 설계서를 정확하게 설명할 수 있습니다. 처음에는 생소하지만 반복하면 자연스럽게 몸에 밥니다. ▶ 계약 관련 핵심 용어 용어 정의 실무 활용 예시 계약자 보험료를 납입하는 사람 (보험 주체) "계약자는 보험료 내시는 분이에요" 피보험자 보험의 대상이 되는 사람 (보장 받는 사람) "피보험자는 실제 보장 받으실 분이에요" 수익자 보험금을 받는 사람 (사망보험금은 보통 가족) "사망 시 보험금 받으실 분은 누구로 할까요?" 보험료 매월 납입하는 금액 "월 보험료는 얼마 정도 생각하세요?" 보험금 사고/질병 발생 시 받는 금액 "암 진단 시 보험금이 5천만 원 나와요" 보험기간 보장이 유지되는 기간 (예: 80세까지) "100세까지 보장되는 상품으로 설계했어요" 납입기간 보험료를 납입하는 기간 (예: 20년납) "20년만 내시고 평생 보장 받으세요" ▶ 보장 관련 핵심 용어 용어 핵심 뜻 고객 언어 1문장 고지의무 청약서 질문에 사실대로 답해야 하는 의무. 애매하면 확인후 답변 단정하지 않고 문구대로 확인해드릴게요. 설명의무 되는 것뿐 아니라 안 되는 구간 (면책/감액/제외)을 설명해야 분쟁이 줄어듦. 보장 안되는 구간도 같이 알려드릴게요. 주계약/특약 기본(주계약)+추가(특약)구조. 특약만 단독인것처럼 말하면 위험. 기본 위에 필요한 보장을 붙이는 구조예요. 면책기간 가입 직후 일정 기간 보장이 안 되는 구간이 있을 수 있음. 처음엔 보장이 바로 시작 안 될 수 있어요. 감액기간 초반엔 100%가 아니라 일부만 지급되는 구간이 있을 수 있음. 초반에는 일부만 나오고, 지나면 정상이에요. 갱신형 /비갱신형 갱신형은 기간마다 보험료가 바뀔 수 있음. 비갱신형은 일정 기간 고정. 가격이 고정인지, 다시 계산되는 구조인지부터 볼게요. 자기부담 (공제) 청구해도 일부는 본인이 부담하는 구조가 있을 수 있음. 전액이 아니라 일부는 본인 부담이 있어요. 보장범위 /지급조건 담보명 같아도 지급 조건은 약관 기준으로 달라질 수 있음. 이름 말고 ‘지급 조건’을 보겠습니다. 부담보 특정 부위/질병을 일정 기간 또는 전기간 제외하는 조건 이 부분은 제외 조건이 붙을 수 있어요. 해지환급금 해지 시 돌려받는 금액. 상품 구조에 따라 없거나 적을 수 있음. 중간에 해지하면 환급이 적을 수 있어요. 보험료/ 납입기간/ 보험기간 내는 돈/내는 기간/보장되는 기간은 다를 수 있음. 언제까지 내고, 언제까지 보장인지부터요. 청약철회 일정 기간 내 청약 취소 가능(조건/기간은 계약 안내 참고). 가입 후에도 일정 기간은 철회가 가능해요. 부활 실효된 계약을 조건에 따라 다시 살리는 절차. 실효되면 다시 살리는 절차가 필요해요. 실효 보험료 미납 등으로 계약 효력이 멈춘 상태.. 미납이 계속되면 보험이 멈출 수 있어요. ▶ 실무에서 자주 쓰는 용어 용어 설명 고지의무 청약 시 건강 상태, 과거 병력 등을 사실대로 알려야 하는 의무. 위반 시 계약 해지 or 보험금 미지급 통지의무 계약 후 중요 사항 변경(직업 변경, 이주 등) 시 보험사에 알려야 하는 의무 계약전 알릴 의무 고지의무와 같은 개념. 5년 이내 입원, 수술, 진단, 투약 이력 등 기재 특약 주계약에 추가하는 보장 항목. 개별 선택 가능하며 별도 보험료 발생 주계약 보험의 기본이 되는 계약. 특약 없이도 존재 가능 환산보험료 설계사 실적 산정 시 사용하는 보험료 기준. 실제 납입 보험료와 다를 수 있음 FP / FC / FA Financial Planner / Financial Consultant /
