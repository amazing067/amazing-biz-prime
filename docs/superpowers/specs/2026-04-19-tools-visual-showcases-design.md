# Tools 섹션 시각 쇼케이스 변환 — 디자인 스펙

**Date:** 2026-04-19
**Scope:** `components/v2/Tools.tsx`의 그룹 3개(설계사 포털 / AI 분석 스튜디오 / 고객접점 콘텐츠)를 텍스트 카드 그리드에서 시각 쇼케이스(콜라주 + 도구 리스트)로 전환. "인프라 · 일체형" 그룹은 기존 카드 유지.

## 1. 목표

- 페이지를 처음 보는 사람이 "이 회사가 어떤 화면을 운영하는가"를 **읽지 않고도** 즉시 감지하게 한다.
- 현재의 6개 텍스트 카드 × 3그룹(=18개 카드)을 **3개의 시각 쇼케이스**로 응축. 정보 밀도는 유지, 시각 임팩트는 상승.
- "Gemini 2.5 Pro" 등 외부 모델/벤더 노출은 모두 제거. 자체 시스템이라는 메시지에 집중.

## 3. 레이아웃 시스템

### 데스크톱 (≥ lg)
공용 그리드: `grid-cols-12`, `gap-12`.
- **포털 / 고객접점:** 콜라주 7칸 (왼쪽), 도구 리스트 5칸 (오른쪽)
- **스튜디오:** 좌우 반전 — 도구 리스트 5칸 (왼쪽), 콜라주 7칸 (오른쪽). 시각 리듬을 깨기 위함.

### 태블릿 (md)
콜라주 위, 도구 리스트 아래로 단순 스택. 콜라주는 `aspect-[4/3]` 유지.

### 모바일 (< md)
콜라주는 가로 스크롤 가능한 단일 가로 행으로 단순화 (조각 2~3개), 도구 리스트는 1열 텍스트 카드 유지(단순 + 가독성).

### 그룹 헤더
기존 헤더 (`0X / SUB`, 그룹명, 설명, "N tools") 유지. 단 sub 텍스트 변경:
- "Gemini 2.5 Pro" → **"AI Studio"**

### 도구 리스트 (오른쪽/왼쪽 컬럼)
- 도구당 한 줄: 좌측 인덱스 (`/01`), 도구명 (16px medium), desc (13px dim).
- 호버 시 → 아래로 detail 텍스트가 부드럽게 펼쳐짐 (기존 ToolCard와 동일한 인터랙션 유지, 단 카드가 아닌 인라인 행).
- 좌측에 1px 액센트 바가 호버 시 나타남.

## 4. 콜라주 조각 스펙

모든 조각은 **순수 SVG / CSS / 텍스트만** 사용. 실 스크린샷 이미지 일절 없음. 페이퍼 베이지 위에 `bg-1`, `bg-2`, `accent` 토큰 조합.

### 4.1 ShowcasePortal — 설계사 포털

콜라주 영역(7칸) 내부 구성:

**A. 실시간 KPI 4칸 (상단 대형)**
- 4개 셀: 업로드 / 배정 / 상담중 / 계약
- 각 셀: 라벨(11px Mono uppercase dim), 큰 숫자(36px tabular), 미니 진행률 바(2px). 숫자는 정적 더미 — 142 / 87 / 31 / 18.
- 가장 오른쪽 "계약" 셀에 🏆 → SVG check 아이콘 + accent 컬러로 100% 달성 강조.

**B. DB 분배 테이블 (좌하단)**
- 3행: FC 이름(가명 — "김 FC", "박 FC", "이 FC") + 배정 수 + 상담 단계 점 4개(TA·1차·2차·클로징, 활성 단계만 accent로 채움).
- 헤더 "DB DISTRIBUTION" Eyebrow.

**C. 캘린더 미니 (우하단)**
- 3일 칼럼 (오늘 / 내일 / 모레). 각 칼럼에 2~3개 시간 점 + 짧은 라벨("TA 콜", "본부 교육", "갱신 미팅").
- 오늘 칼럼 상단에 accent 색 4px 바.

조각 배치: CSS Grid 7칸 안 `grid-rows-[auto_1fr]`, A는 row 1 가로 풀폭, B/C는 row 2 좌우 분할.

### 4.2 ShowcaseStudio — AI 분석 스튜디오

콜라주 영역(7칸) 내부 구성:

**A. 보장분석 5단계 KPI 흐름 (상단 가로 풀폭)**
- 5개 노드 가로 정렬: "현재 → 정리 예정 → 정리 후 → 새 제안 → 최종 월납"
- 각 노드: 스테이지 라벨(11px Mono) + 월납 금액(20px tabular, 더미 ₩134k → ₩98k → ₩72k → ₩88k → ₩155k) + 화살표 connector (1px line + arrowRight icon).
- 마지막 노드 "최종" 칸은 액센트 outline + accent ink.

**B. 인지검사 레이더 차트 (좌하단)**
- 8각 SVG 레이더 (8개 뇌영역 라벨 — 기억력/주의력/언어/시공간/실행/계산/추론/속도).
- 2개 폴리곤 레이어: 회색 점선(기준), accent 채움 30% opacity(현재 점수). 정적 더미 좌표.
- 헤더 "COGNITIVE · 8 REGIONS" Eyebrow.

**C. AI 입력 필드 (우하단)**
- 점선 박스: "PDF 증권 업로드" + sparkles 아이콘 + AI 배지(accent).
- 박스 아래 짧은 더미 텍스트 라인 3줄 (스켈레톤 라인) — "32개사 자동 매칭", "5단계 KPI 재계산", "근거 n건 표시".
- **벤더/모델명 일절 표기 안 함.**

배치: row 1 = A (풀폭), row 2 = B (좌) + C (우).

### 4.3 ShowcaseTouchpoints — 고객접점 콘텐츠

콜라주 영역(7칸) 내부 구성:

**A. 모바일 프레임 청구.com (좌측 큰 세로)**
- 폰 형태 SVG/CSS 프레임 (aspect 9/19, 라운드 코너).
- 상단 "청구.com" 헤더 + 검색 바 placeholder.
- 아래 4×2 그리드 = 보험사 8칸. 각 칸: 회사 약자(2글자 — "삼", "한", "DB", "흥", "교", "현", "메", "라") + 도트 라벨.
- 하단 "PDF 청구서 · 인콜 · FAX" 마이크로 텍스트.

**B. 알림톡 풍선 (우상단)**
- 카카오톡 스타일 풍선 (좌측 노란 점 + 회색 풍선 박스).
- 풍선 텍스트: "[Amazing] 김ㅇㅇ님 갱신 안내 — 5월 12일까지 진행 부탁드립니다." (3줄)
- 발송 시각 미니 텍스트.

**C. 블로그 카드 (우하단)**
- 미니 카드 2개 세로 스택.
- 각 카드: 4px accent 좌측 바 + 제목 1줄 + 날짜·태그 micro text.
- 더미 제목 — "실손 4세대 청구 가이드 (2026)" / "치매 진단 후 보장 정리 케이스".

배치: A는 row 1~2 좌측 풀높이 (col-span-5), B/C는 row 1, 2 우측 분할 (col-span-7).

## 6. 데이터 / 더미 콘텐츠 정책

- 모든 더미 숫자·이름은 **눈에 띄게 가짜**(가명, 라운드 숫자)로 — 신뢰도 오해 방지.
- "더미"임을 별도 워터마크로 표시하지는 않음. 시각 톤만으로 "프로토타입 캡쳐"가 아닌 "디자인 표현"임이 분명하도록.
- 더미 데이터는 컴포넌트 파일 상단 `const` 객체로 모음.

## 7. 인터랙션

- 콜라주 조각: **정적**. 호버나 클릭 시 미세한 lift(`translate-y-[-1px]`) 정도만. 애니메이션 라이브러리 도입 없음.
- 도구 리스트 행: 기존 ToolCard와 동일한 호버-펼침 (max-height + opacity transition, 500ms cubic-bezier).
- 그리드 오버레이/노이즈는 섹션 단위에서 이미 적용되어 있으므로 추가하지 않음.

---

## 8. 접근성 / 반응형

- 모든 SVG에 `aria-hidden`, 콜라주 자체는 `role="img"` + `aria-label="설계사 포털 시각 요약"` 패턴.
- 텍스트 정보는 도구 리스트가 모두 책임짐 → 콜라주는 보조 시각.
- 모바일에서 콜라주 가로 스크롤은 `snap-x snap-mandatory` 사용, 스크롤 힌트 없이 자연스러운 손동작에 의존.

## 10. 수용 기준

1. `npm run build` 통과, 새 lint 경고 없음.
2. 데스크톱 1440 / 태블릿 768 / 모바일 375 세 폭에서 시각적으로 깨짐 없음.
3. 페이지 전체에서 "Gemini 2.5 Pro" 문자열이 **검색되지 않음**.
4. 3개 그룹의 시각 쇼케이스가 각각 다른 콜라주 구성을 가짐 (복사·붙여넣기 단조로움 없음).
5. 호버 시 도구 detail이 펼쳐지는 기존 인터랙션이 깨지지 않음.
